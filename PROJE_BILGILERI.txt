================================================================================
2. VERITABANI TABLO YAPISI
================================================================================

Tablo Adi: movies

Sutunlar:
- id          : SERIAL PRIMARY KEY (Otomatik artan)
- title       : VARCHAR(255) NOT NULL (Film basligi)
- genre       : VARCHAR(100) (Film turu)
- year        : INTEGER (Yapim yili)
- rating      : REAL (Puan - 0-10 arasi)
- description : TEXT (Film aciklamasi)
- poster_url  : TEXT (Afiş URL'si)

================================================================================
3. KULLANILAN TEKNOLOJILER
================================================================================

Python Versiyonu: 3.x
GUI Framework: PyQt6
Veritabani: PostgreSQL (psycopg2-binary)
HTTP Istekleri: requests
Goruntu Islemleri: PyQt6.QtGui (QPixmap)
Film Veri API: OMDb API (http://www.omdbapi.com/)

Paketler:
- PyQt6>=6.0.0
- requests>=2.28.0
- psycopg2-binary>=2.9.0

API Key:
- OMDb API Key gerekli (https://www.omdbapi.com/apikey.aspx)
- Ucretsiz: Gunluk 1000 istek limiti
- API key main.py'de veya environment variable olarak ayarlanabilir
